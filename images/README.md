# Career Manager images

This directory stores repository-managed image assets used by the Career Manager project.

Use descriptive, lowercase filenames with hyphens. Keep private or user-uploaded images out of the repository; those belong in the application’s configured storage/gallery system. Optimize production assets before committing them, and prefer WebP or SVG when appropriate.

The deployed application may also serve public web assets from `public/`; this directory is intended for source-controlled project images and design assets.
